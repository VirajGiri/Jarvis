# J.A.R.V.I.S.

Windows-first, 24/7 multi-agent AI platform with a React motion/3D command interface.

## Foundation
- React + TypeScript desktop UI
- Three.js / React Three Fiber
- Framer Motion
- Monorepo structure
- Runtime, agent and security architecture documentation
- Development branch: `jarvis-foundation`

## Safety
PC control remains locked until the permission and tool gateway is implemented. LLM output must never receive unrestricted operating-system access.
